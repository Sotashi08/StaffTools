# StaffTools

**StaffTools** — клиентский мод для Minecraft (Fabric 1.21.1), набор инструментов для модерации серверов. Всё работает на стороне клиента: ничего не отправляет на сервер, кроме команд, которые ты сам вызвал.

- **Автор:** uwdie
- **Версия:** 1.0-SNAP
- **Minecraft:** 1.21.1 · **Fabric Loader:** ≥ 0.19.3 · **Fabric API:** требуется
- **Лицензия:** MIT
- **Открыть меню:** Right Shift (настраивается в vanilla Controls)

---

## Возможности

### 🔗 Умный чат
- Ники игроков в чате подсвечиваются и становятся кликабельными;
- Работает даже на серверах с кастомным форматированием чата: детект через hover/события, display-name из tab-list'а, очистку цветовых кодов, обучение алиасам ников;
- Клик по нику → попап действий, Shift+клик → копирование ника.

### ⚡ Попап действий
- Панель с быстрыми действиями над игроком (мут, бан, кик, варн + свои пункты);
- Подтверждение опасных действий двойным кликом с 3-секундным таймером и угасанием;
- Перетаскивание за угол, скролл, счётчик наказаний игрока (NP) из локальной истории.

### 🛠 Макросы
- Свои макросы с плейсхолдерами: `<player>`, `<staff>`, `<x>`, `<y>`, `<z>`, `<ping>`, `<health>`, `<server>`;
- Флаг «Подтверждение» для опасных команд;
- Дефолтные макросы создаются автоматически при первом запуске.

### 📜 История наказаний
- Автоматически логирует твои ban/mute/kick/warn/freeze команды;
- Фиксирует ответ сервера (успех / ошибка / нет ответа);
- Игнорирует наказания, выданные другими модераторами — только твоя статистика.

### 🔔 Прочее
- Toast-уведомления со слайд-анимацией (отключаются в настройках);
- Выбор эмодзи для иконок действий и макросов;
- Локализация RU / EN.

## Установка
1. Установи [Fabric Loader](https://fabricmc.net/use/) для 1.21.1;
2. Положи `StaffTools.jar` и [Fabric API](https://modrinth.com/mod/fabric-api) в папку `mods`;
3. Запусти игру, нажми **Right Shift** в мире.

## Конфигурация
- `config/stafftools.json` — настройки, макросы, пункты действий;
- `config/stafftools_history.json` — история наказаний (до 300 записей).

## Совместимость
Мод полностью клиентский (`environment: client`) — можно заходить на любые сервера; на сервере присутствие мода не требуется и не проверяется.
