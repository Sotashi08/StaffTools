# StaffTools

**StaffTools** — клиентский мод для Minecraft на Fabric. Он помогает модераторам быстрее находить игроков в чате, выполнять макросы и смотреть историю наказаний.

- Версия мода: **1.5.0-resync**
- Minecraft: **1.21.11**
- Автор: **uwdie**
- Лицензия: **MIT**

## Что умеет мод

- Находит ники игроков в чате и делает их кликабельными.
- Показывает окно действий над игроком.
- Выполняет макросы с плейсхолдерами и алиасами.
- Показывает историю наказаний и ответ сервера.
- Собирает аудит-действия и данные профилировщика.
- Показывает модераторский HUD рядом с чатом.
- Поддерживает темы, градиенты, анимации и настройки интерфейса.
- Рисует стилизованную карточку статистики игрока при наведении на ник.
- Карточка находится ближе к курсору, без аватарки, а в нижней строке показывает обращённые фразы к игроку.
- Показывает скруглённую рамку чата в стиле StaffTools.
- Поддерживает русскую и английскую локализацию (строки в `assets/stafftools/lang/*.json`).
- Встроенный гайдбук со справкой по всем функциям (внизу панели разделов главного меню).

## Основные настройки

Открыть главное меню StaffTools можно клавишей **Right Shift**.

В разделе «Настройки мода» есть переключатель:

**Не подсвечивать ники**

Когда он включён:

- ни один найденный ник не получает дополнительную цветную подсветку;
- текст чата и цвета сервера остаются прежними;
- ники остаются кликабельными;
- всплывающая информация по игроку остаётся доступной.

Пример: у игрока реальный ник `uwdie`, а видимый ник через плагин — `uwdiesol`. Ник `uwdiesol` не будет подсвечиваться модом, а текст сервера останется прежним.

## Установка

1. Установите Fabric Loader и Fabric API для Minecraft 1.21.11.
2. Положите `StaffTools-1.5.0-resync.jar` в папку `mods`.
3. Запустите Minecraft.
4. Нажмите **Right Shift**, чтобы открыть StaffTools.

Мод работает только на стороне клиента. На сервере устанавливать StaffTools не требуется.

## Использование макросов

Макрос — это команда с подстановками:

```text
/mute <player> 10m
/warn <player> Нарушение правила
/msg <player> <alias>
```

Доступные плейсхолдеры:

| Плейсхолдер | Что вставляется |
|---|---|
| `<player>` | Ник выбранного игрока |
| `<staff>` | Ваш ник |
| `<x>` `<y>` `<z>` | Ваши координаты |
| `<ping>` | Пинг выбранного игрока |
| `<server>` | Адрес сервера |
| `<alias>` | Выбранный пункт алиаса |
| `<reason>` | Причина, вводится вручную в окне перед отправкой |

Алиасы можно менять в редакторе макроса. Для нескольких вариантов используется список слева, перетаскивание и отдельное окно выбора перед отправкой.

## Файлы мода

- `config/stafftools.json` — настройки, профили, макросы и действия;
- `config/stafftools_history.json` — история наказаний;
- лог аудита — окно «Аудит / Профилировщик» внутри мода.

## Сборка проекта

Нужны JDK 21 или новее.

```bat
gradlew.bat build
```

Для сборки без запуска тестовой задачи:

```bat
gradlew.bat build -x test
```

Готовый jar появляется в папке `build/libs`.
