# StaffTools

**StaffTools** — клиентский мод для Minecraft (Fabric 1.21.1), набор инструментов для модерации серверов. Работает на стороне клиента.

- **Автор:** uwdie
- **Версия:** 1.0-SNAP
- **Minecraft:** 1.21.1 · **Fabric Loader:** ≥ 0.19.3 · **Fabric API:** требуется
- **Лицензия:** MIT

---

## Возможности

### 🔗 Умный чат
- Ники игроков в чате подсвечиваются и становятся кликабельными (Бета-версия, работает на серверах без кастомного форматирования);
- Работает даже на серверах с кастомным форматированием чата: детект через hover/события, display-name из tab-list'а, очистку цветовых кодов, обучение алиасам ников;
- Клик по нику → окно действий.

### ⚡ Попап действий
- Панель с быстрыми действиями над игроком;
- Подтверждение опасных действий двойным кликом с 3-секундным таймером;
- Перетаскивание за угол, скролл, счётчик наказаний игрока из локальной истории.

### 🛠 Макросы
Макрос — это команда (или шаблон команды) с плейсхолдерами, которая выполняется в два клика из попапа действий.

**Плейсхолдеры:**

| Плейсхолдер | Что подставляется | Пример |
|---|---|---|
| `<player>` | Ник игрока-цели | `/mute <player> 10m` → `/mute Notch 10m` |
| `<staff>` | Ваш ник | `/msg <player> Проверка (<staff>)` |
| `<x>` `<y>` `<z>` | Ваши координаты (блоки) | `/tp <player> <x> <y> <z>` |
| `<ping>` | Пинг цели в мс | `/warn <player> лаги (<ping>ms)` |
| `<server>` | Адрес текущего сервера | `/tell <player> заходим на <server>` |
| `<alias>` | Выбранный вариант из списка алиасов | см. ниже |

**Алиасы (`<alias>`)** — для правил, у которых одна команда, но много трактовок
(например, «4.6 Флуд, мат, ослабление, капс»):

1. В редакторе макроса напишите команду с `<alias>`, например: `/mute <player> <alias>`;
2. В панели «Алиасы» слева добавьте варианты: `30m Мат`, `10m Капс`, `Флуд`;
3. При выполнении макроса откроется окно выбора пункта;
4. Выбрали «30m Мат» → отправится `/mute Notch 30m Мат`.

Если список алиасов пуст — `<alias>` заменяется пустотой и макрос выполняется сразу.
Время и причина пишутся **внутри алиаса**, поэтому один макрос покрывает всё правило.

**Подтверждение:** флаг «Подтверждение» помечает макрос опасным — перед выполнением
нужно кликнуть по нему второй раз в течение 3 секунд (строка подсвечивается красным,
по ней бежит таймер-полоска).

- Дефолтные макросы (Day, Night, Teleport, Mute) создаются при первом запуске;
- Иконки выбираются из встроенного набора эмодзи.

### 📜 История наказаний
- Автоматически логирует ban/mute/kick/warn/freeze;
- Фиксирует ответ сервера (успех / ошибка / нет ответа);
- Игнорирует наказания, выданные другими модераторами.

### 🔔 Прочее
- Toast-уведомления со слайд-анимацией и прогрессом времени (отключаются в настройках);
- Темы оформления: Океан / Изумруд / Аметист / Закат — меняются на ходу;
- Выбор эмодзи для иконок действий и макросов;
- Локализация RU / EN.

## Установка
1. Установить [Fabric Loader](https://fabricmc.net/use/) для 1.21.1;
2. Положить `StaffTools.jar` и [Fabric API](https://modrinth.com/mod/fabric-api) в папку `mods`;
3. Использование → **Right Shift**.

## Конфигурация
- `config/stafftools.json` — настройки, макросы, пункты действий;
- `config/stafftools_history.json` — история наказаний (до 300 записей).

## Совместимость
Мод полностью клиентский (`environment: client`) — можно заходить на любые сервера; на сервере присутствие мода не требуется и не проверяется.
