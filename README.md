# StaffTools

**StaffTools** — клиентский мод для Minecraft (Fabric 1.21.1), набор инструментов для модерации серверов. Работает на стороне клиента.

- **Автор:** uwdie
- **Версия:** 1.0-SNAP
- **Minecraft:** 1.21.1 · **Fabric Loader:** ≥ 0.19.3 · **Fabric API:** требуется
- **Лицензия:** MIT

---

## Возможности

### 🔗 Умный чат
- Ники игроков в чате подсвечиваются и становятся кликабельными (Бета-версия, работает на серверах без кастомного форматирования);
- Работает даже на серверах с кастомным форматированием чата: детект через hover/события, display-name из tab-list'а, очистку цветовых кодов, обучение алиасам ников;
- Клик по нику → окно действий.

### ⚡ Попап действий
- Панель с быстрыми действиями над игроком;
- Подтверждение опасных действий двойным кликом с 3-секундным таймером;
- Перетаскивание за угол, скролл, счётчик наказаний игрока из локальной истории.

### 🛠 Макросы
- Свои макросы с плейсхолдерами: `<player>`, `<staff>`, `<x>`, `<y>`, `<z>`, `<ping>`, `<health>`, `<server>`;
- Флаг «Подтверждение» для опасных команд;
- Дефолтные макросы создаются автоматически при первом запуске.

### 📜 История наказаний
- Автоматически логирует ban/mute/kick/warn/freeze;
- Фиксирует ответ сервера (успех / ошибка / нет ответа);
- Игнорирует наказания, выданные другими модераторами.

### 🔔 Прочее
- Toast-уведомления (отключаются в настройках);
- Выбор эмодзи для иконок действий и макросов;
- Локализация RU / EN.

## Установка
1. Установить [Fabric Loader](https://fabricmc.net/use/) для 1.21.1;
2. Положить `StaffTools.jar` и [Fabric API](https://modrinth.com/mod/fabric-api) в папку `mods`;
3. Использование → **Right Shift**.

## Конфигурация
- `config/stafftools.json` — настройки, макросы, пункты действий;
- `config/stafftools_history.json` — история наказаний (до 300 записей).

## Совместимость
Мод полностью клиентский (`environment: client`) — можно заходить на любые сервера; на сервере присутствие мода не требуется и не проверяется.
