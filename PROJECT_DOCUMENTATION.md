# StaffTools — техническая документация

## Основная информация

- Проект: StaffTools
- Версия мода: `1.5.0-resync`
- Minecraft: `1.21.11`
- Loader: Fabric Loader `0.20.0`
- Fabric API: `0.141.6+1.21.11`
- Yarn mappings: `1.21.11+build.6`
- Java: 21
- Среда выполнения: только client
- Автор: uwdie
- Лицензия: MIT

Мод не требует установки на сервер. Клиентский jar работает на обычных серверах через Fabric API.

---

## Назначение проекта

StaffTools объединяет инструменты модератора в одном интерфейсе:

- поиск ников в тексте чата;
- клик и всплывающая панель действий;
- макросы и алиасы;
- история наказаний;
- аудит-действий;
- профилировщик;
- темы и анимации;
- модераторский HUD;
- локализация RU/EN.

## Главные пакеты

### `client.chat`

Отвечает за обработку чата и ники игроков:

- `ChatTextProcessor` — проходит по текстовому дереву сообщения и добавляет кликабельность;
- `PlayerMentionDetector` — объединяет способы поиска ников;
- `EssentialsNickTracker` — отслеживает изменённые ники EssentialsX;
- `NickAliases` — хранит выученные псевдонимы отображения;
- `NickCache` — кеш видимых в игре ников;
- `ChatLinePicker` — точно определяет ник под курсором;
- `NickStats` — формирует данные для всплывающей панели.

### `client.config`

- `StaffToolsConfig` — все live-настройки мода;
- `ConfigManager` — чтение и запись JSON через Gson;
- `Profile` / `ProfileSettings` — наборы сохраняемых настроек;
- `ActionEntry` — пункт меню действий.

### `client.macro`

- `Macro` — модель макроса;
- `MacroManager` — список макросов;
- `MacroEditorScreen` — редактор макроса;
- `MacroExecutor` — отправка команд;
- `MacroValidator` — проверка опасных корней команд;
- `PlaceholderEngine` — замена плейсхолдеров;
- `CommandPreview` — предварительный просмотр результата.

### `client.punishment`

- `PunishmentHistory` — история и сопоставление ответов сервера;
- `PunishmentRecord` — отдельная запись наказания;
- `PunishmentStatus` / `PunishmentType` — состояние и тип наказания;
- `CommandAnalyzer` — определение наказания и автора из команды.

### `client.ui`

- `StafftoolsScreen` — главное меню;
- `SettingsScreen` — общие настройки;
- `DetectionSettingsScreen` — методы детекта ников;
- `ThemesScreen` — темы и градиенты;
- `PlayerActionOverlay` — попап действий;
- `ModeratorHud` — HUD модератора;
- `AuditScreen` — аудит и профилировщик;
- `StScreen`, `StListScreen`, `StShell` — общая система интерфейса.

### `client.audit`

- `AuditLog` — журнал действий мода;
- `AuditCategory` — категории записей;
- `AuditLevel` — тип записи;
- `Profiler` — замеры команд, детекта, макросов и других действий.

## Работа чата

Есть несколько независимых способов определить ник игрока:

1. реальный ник из tab-list;
2. кэш ников, виденных в текущей сессии;
3. Unicode-подмена похожих символов;
4. удаление декоративных символов;
5. снятие Legacy-цветовых кодов;
6. изменённый ник EssentialsX;
7. выученный alias через click/hover-событие;
8. точный hit-testing клика по отрисованному тексту.

Найденные диапазоны объединяются в `PlayerMention`. Это позволяет сохранить два свойства:

- ник остаётся кликабельным;
- подсветка может быть отключена без потери клика или всплывающей панели.

При наведении на ник используется отдельная карточка `NickStats`:

- аватар игрока из tab-list;
- онлайн/офлайн статус;
- пинг и игровой режим;
- локальное количество наказаний;
- сервер;
- подсказка для левого клика;
- строка с адресной фразой для конкретного ника: фраза меняется при каждом новом наведении;
- компактное расположение близко к курсору без аватарки;
- плавное появление с скруглёнными панелями и accent-топом.

Vanilla-hover текста заменён кастомным рендером только для ников StaffTools.

### Изменённые ники EssentialsX

EssentialsX хранит реальный ник профиля отдельно от его изменённого отображаемого имени.

`EssentialsNickTracker` запоминает:

- ники из текстовых изменений вида `old is now known as new`;
- простые изменённые ники в tab-list;
- имя с префиксом или рангом;
- имя с декорациями.

Настройка общей подсветки:

```text
Не подсвечивать ники
```

лежит в общей панели «Настройки мода».

Параметр конфига:

```java
private boolean nickHighlightDisabled = false;
```

Он сохраняется:

- в `StaffToolsConfig`;
- в `ProfileSettings`;
- вместе с остальными настройками профиля;
- в `config/stafftools.json`.

При включённой настройке дополнительная подсветка отключается у всех найденных ников:

- обычные ники;
- ники EssentialsX;
- выученные алиасы;
- ники с Unicode или декоративным форматированием.

Переключатель не отключает:

- детект ника;
- клик по нику;
- всплывающую панель и действия;
- оригинальный цвет текста сервера.

## Макросы

Макрос содержит:

- название;
- описание;
- иконку;
- включённый или выключенный статус;
- список команд;
- алиасы;
- флаг подтверждения опасного действия.

Плейсхолдеры:

| Плейсхолдер | Результат |
|---|---|
| `<player>` | Ник выбранной цели |
| `<staff>` | Ник модератора |
| `<x>` `<y>` `<z>` | Координаты модератора |
| `<ping>` | Пинг цели |
| `<server>` | Адрес сервера |
| `<alias>` | Выбранный пункт алиаса |

Перед отправкой команды проходят:

- форматная проверка;
- проверка длины;
- denylist опасных команд;
- проверка имени цели для известных moderation-команд;
- проверка алиаса.

Неизвестные серверные команды не отсекаются как произвольные. Это позволяет пропускать команды собственных плагинов.

## История наказаний

История сохраняет до 300 записей в `config/stafftools_history.json`.

Запись содержит:

- имя игрока;
- тип наказания;
- отправленную команду;
- время;
- состояние;
- ответ сервера;
- источник: макрос, действие или ручная команда.

Состояния:

- `PENDING` — ответ ещё не получен;
- `DONE` — сервер подтвердил результат;
- `NO_RESPONSE` — таймаут ответа.

## Аудит и профилировщик

Меню «Аудит» объединяет:

- журнал всех действий мода;
- успешные и отклонённые детекты;
- запуск макросов;
- исполнение действий;
- результаты наказаний;
- замеры времени и частоты срабатываний.

`Profiler` записывает только базовые показатели выполнения и не добавляет сетевую передачу данных.

Профили позволяют сохранить и переключать отдельные наборы:

## Темы и интерфейс

Поддерживаются градиентные темы и анимации:

- Ocean;
- Emerald;
- Amethyst;
- Dawn;
- Aurora;
- Neon;
- Sunset;
- Twilight;
- Sakura;
- Glacier;
- Mint;
- Plum.

Интерфейс использует общую палитру `Ui`, общие компоненты `StButton`, `StToggle`, `StTextField`, анимации входа и hover-состояния.

Визуальные элементы чата оформлены по тому же дизайну:

- карточка игрока при наведении имеет rounded-корпус, accent ribbon, аватар и сетку статистики;
- vanilla hover-tooltip заменён кастомным рендером для ников StaffTools;
- рамка чата имеет скруглённые углы, мягкую тень, внутреннюю линию и orbit-свечение;
- при наведении на grip и во время resize рамка усиливает акцент.

Горячие клавиши:

- `Right Shift` — открыть/закрыть главное меню StaffTools;
- `ESC` — закрыть экраны и всплывающие панели.

Основные файлы:


## Важные технические ограничения

- весь UI-рендер использует клиентские API Minecraft;
- серверная авторизация не используется;
- мод не отправляет команды без явного макроса или действия;
- опасные команды блокируются валидатором;
- постоянные ники и кэш очищаются при завершении сессии;
- клиентский текст не должен теряться при полной перерисовке chat-сообщения;
- анимации отключаются общим переключателем `Анимации`.
